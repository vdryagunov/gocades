PAdES: PDF → дайджест → SignHash → Assemble

Локальный сервер делает pdfsign.Prepare / Assemble. Плагин — SignHash по hex-дайджесту (сейчас всегда ГОСТ 2012-256). PIN / пароль контейнера на странице не вводится: его спросит окно КриптоПро при доступе к ключу. Выберите сертификат с ключом ГОСТ Р 34.10-2012 256 (не 512 и не RSA) — иначе часто будет 0x80070057.
